Vocabulary Builder
 
A full-stack web application for building and expanding your vocabulary. Users can sign up, log in, and manage their personal vocabulary list through a clean and simple interface.
 
---
 
Features
 
- User authentication (Sign Up / Login)
- Personal vocabulary management
- Clean frontend UI with HTML, CSS, and JavaScript
- RESTful backend API with Node.js
- JSON-based data storage
---
 
Tech Stack
 
**Frontend:**
- HTML5
- CSS3
- JavaScript (Vanilla)
**Backend:**
- Node.js
- Express.js
**Data:**
- JSON file (`db.json`) for data persistence

Getting Started
 
 Prerequisites
 
Make sure you have the following installed:
 
- [Node.js](https://nodejs.org/) (v14 or higher)
- npm (comes with Node.js)
 Installation
 
1. **Clone the repository:**
   ```bash
   git clone https://github.com/kehh-keh/Vocabulary-Builder.git
   ```
 
2. **Navigate into the project folder:**
   ```bash
   cd vocabulary-builder
   ```
 
3. **Install dependencies:**
   ```bash
   npm install
   ```
 
4. **Start the server:**
   ```bash
   node backend/server.js
   ```
 
5. **Open the app in your browser:**
   ```
   http://localhost:5500
   ```
